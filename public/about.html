About This Demo

Built for puzzle #21 in the "automate-me-this-puzzle" series: connect Google Analytics to a website. The site is three static pages deployed on Cloudflare Workers. Each page loads the real GA4 gtag.js snippet, so visiting any page here fires a real pageview event against a live GA4 property.

Navigate between pages to generate pageview events, or go to the Contact page to fire a custom lead-generation event.

GA4 Measurement ID: G-20V51SLEJJ (AiOlogy.live property, reused for this demo — see README)
