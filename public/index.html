Puzzle #21: Google Analytics, Wired In For Real

This is a small demo site built to prove a real GA4 (gtag.js) tag is installed and registering real events, not just pageviews.

What's being tracked

  • Default pageview, automatically, on every page via gtag('config', ...)
  • A custom cta_click event when the button above is clicked
  • A custom generate_lead event when the contact form is submitted

GA4 Measurement ID: G-ZF4H9HZJQF (dedicated property created for this demo)
